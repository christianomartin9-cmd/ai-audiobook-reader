# Roadmap

## 1. Foundation
Build the Android application shell and establish the project architecture.

## 2. PDF to text
Allow a user to select a PDF and extract clean, readable text.

## 3. Basic narration
Convert extracted text into playable speech.

## 4. Expressive AI narration
Add a story-director layer that identifies scenes, emotion, pacing and dialogue context before voice generation.

## 5. Character voices
Detect recurring characters and assign consistent voices and delivery styles.

## 6. Offline audiobooks
Generate chapter-sized audio files, save them locally, and provide offline playback. Target efficient spoken-word encoding such as Opus.

## 7. URL support
Allow users to paste supported URLs and turn readable content into narration.

## 8. Library and accessibility
Add books, chapters, bookmarks, progress tracking, storage management and accessibility-focused UI.

## 9. Community release
Publish APK builds, document setup, accept contributions and improve the project from community feedback.
